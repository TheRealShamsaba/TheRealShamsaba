# Profile artwork

Original SVG compositions made for Arian Shamsabadi's GitHub profile. The nameplate combines a serif masthead, an off-axis electric-blue asterisk, and a compact monospace colophon. Light/dark variants use GitHub's theme-specific image fragments. Project panels use original vector knight/checkerboard and film-frame motifs; they do not illustrate benchmark outcomes.

`drip-live.jpg` is an intact in-app-browser screenshot of the public https://dressrightinpublic.com/ homepage captured on 25 October 2026. It is a website image, not a claim that the iPhone beta is publicly available. The screenshot bytes are unchanged.

The SVGs have fixed viewBoxes, system-font fallbacks, descriptive titles, and no scripts, external fonts, remote images, filters, or foreignObject. All project descriptions, status labels, links, and credit are repeated as native README text so the artwork is not the only way to understand the profile.
